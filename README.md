# PWGOODSTORE
Расширение на ключи и подписки

Пока работает вариант на единоразовое (если перезайти в браузер/перезагрузить компьютер уже не будет работать)

1. Распакуй скачанный ZIP с GitHub
2. Удали файл README.md из папки
3. Открой Firefox → about:debugging
4. Нажми "Этот Firefox" → "Загрузить временное дополнение"
5. Выбери файл manifest.json из твоей папки
6. Готово! Расширение будет работать
