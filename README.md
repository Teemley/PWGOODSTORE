# PWGOODSTORE
Расширение на ключи и подписки
Что бы установить
1. Скачайте и распакуй архив
2. Удалите Readme в распакованной папке 
3. Открой Chrome --> chrome://extensions/
4. Включи "Режим разработчика" (правый верхний угол)
5. Нажми "Загрузить распакованное расширение"
6. Выбери папку "PWGOODSTORE-main"
7. Всё.
